# Security Policy

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository. Include the
affected version, a minimal reproduction when safe, the expected security
property, and the observed behavior. Do not include production credentials, real
user data, private keys, access or refresh tokens, DPoP proofs, attestation
objects, assertions, challenges, or unredacted request bodies.

We will acknowledge a report, assess affected versions, coordinate a fix and
release, and publish an advisory when disclosure is appropriate.
